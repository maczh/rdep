# 2026-10-08

- 修复 rdep-client 站点管理器窗口：
  - 改为 `.default_size()` + `.resizable(true)` + `.min_size()`，解决高度不自动匹配且无法手动调整的问题；
  - 为站点管理器内两个 `ScrollArea` 与 `CollapsingHeader` 添加唯一 `id_salt`，消除 egui debug 构建下的重复 ID 警告（红色提示标签）。
- 进一步修复站点管理器对话框高度：
  - 将窗口默认高度从 540 提高到 720，使「常规」标签页所有字段无需滚动即可完整显示；
  - 将右侧标签页内容 `ScrollArea` 的 `auto_shrink` 改回 `[true; 2]`，让内容区按实际高度收缩，避免默认状态下出现内部滚动条。
- 修复 SFTP 自定义端口保存后被覆盖为默认 22 的 bug：
  - 移除 `sites_window` 末尾的「全局协议切换同步端口」逻辑，避免选中站点后渲染窗口时把自定义端口覆盖回协议默认值；
  - 把端口同步逻辑移到「常规」标签页的协议下拉框内部，仅在用户**主动切换协议**时回填默认端口；
  - 新增单测 `sites_window_preserves_sftp_custom_port` 验证选中自定义端口 SFTP 站点后不会被覆盖。
- 进一步修复站点管理器高度/缩放：
  - 给窗口显式 ID `site_manager_v2`，绕过 egui 已持久化的旧窗口尺寸，使新的默认尺寸生效；
  - 默认高度从 720 提高到 760，给高 DPI / 额外内边距留出余量；
  - 右侧内容 `ScrollArea` 改回 `auto_shrink([false; 2])`，让内容区随窗口高度自动填充，避免默认出现内部滚动条。
- `cargo check -p rdep-client --features gui`、新增 SFTP 端口单测、站点管理器渲染单测均通过；另有 4 个已有 i18n 相关单测因当前环境输出中文而失败，与本次改动无关。
